# Nova Retail Limited – Integrated Financial Model & DCF Valuation

## Project Overview

This project involves building an integrated three-statement financial model and performing a Discounted Cash Flow (DCF) valuation for Nova Retail Limited, a fictional retail company.

The model analyses historical financial performance, forecasts future business operations over a five-year period, and estimates the company's intrinsic value using the DCF methodology.

## Project Objectives

- Analyse historical financial performance.
- Develop five-year financial projections from FY2027 to FY2031.
- Build an integrated Income Statement, Balance Sheet, and Cash Flow Statement.
- Forecast operating performance and working capital requirements.
- Estimate Free Cash Flow to the Firm (FCFF).
- Calculate Weighted Average Cost of Capital (WACC).
- Determine Enterprise Value and Equity Value.
- Perform sensitivity analysis using different WACC and terminal growth assumptions.

## Model Structure

The financial model consists of the following components:

1. Historical Financial Analysis (FY2024–FY2026)
2. Revenue and Operating Expense Forecasts
3. Integrated Three-Statement Financial Model
4. Working Capital Schedule
5. Property, Plant & Equipment (PP&E) Schedule
6. Debt and Interest Schedule
7. Free Cash Flow to Firm (FCFF) Calculation
8. WACC Calculation using CAPM
9. Terminal Value using the Gordon Growth Model
10. Enterprise Value and Equity Value Calculation
11. Sensitivity Analysis
